BACKUP E RECOVERY - MYSQL

1. BACKUP DO BANCO ECOMMERCE

"C:\Program Files\MySQL\MySQL Server 26.7\bin\mysqldump.exe" -u root -p --single-transaction --set-gtid-purged=OFF --routines --events --triggers ecommerce > "C:\Users\SeuUsuario\ecommerce_backup.sql"


2. RECOVERY DO BANCO ECOMMERCE

"C:\Program Files\MySQL\MySQL Server 26.7\bin\mysql.exe" -u root -p ecommerce < "C:\Users\SeuUsuario\ecommerce_backup.sql"
