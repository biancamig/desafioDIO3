Desafio - Transações, Backup e Recovery
Projeto desenvolvido como parte do desafio de Banco de Dados da DIO, utilizando MySQL.

Objetivo
Praticar o gerenciamento de transações, criação de procedures com tratamento de erros e execução de backup e recuperação de bancos de dados.

Etapas desenvolvidas

Parte 1 - Transações
- Utilização de START TRANSACTION.
- Controle de autocommit.
- Operações INSERT e UPDATE.
- Utilização de COMMIT e ROLLBACK.

Parte 2 - Transações com Procedures
- Criação de procedure para registro de pedidos.
- Utilização de parâmetros de entrada.
- Tratamento de erros com DECLARE EXIT HANDLER.
- Aplicação de ROLLBACK e COMMIT.

Parte 3 - Backup e Recovery
- Backup dos bancos ecommerce e company_constraints utilizando mysqldump.
- Recuperação dos bancos utilizando mysql.
- Inclusão de procedures, eventos e triggers nos backups.
- Criação e teste de evento no MySQL.


Tecnologias utilizadas

- MySQL
- MySQL Workbench
- MySQL Command Line (CMD)
- GitHub
